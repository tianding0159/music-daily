# 原版 UI 精修验收记录 · 2026-09-07

按现有灰白工业网格、黑色铭牌、细线、橙色点缀、LCD 小猫及唱盘继续精修。实现位于本地 `codex/ui-refine-existing` 工作树，基于 main 的 `cb902cb947cac795ab6e719e67f829b01655ddf6`。本轮未 commit、push、合并或发布；旧改版草稿未被合并。

## 已完成

- 首页保留唱盘：入口改为原生即时链接，首帧即可见，轻微入场动画 220ms；手机短屏可访问底部入口，移除继承播放器造成的多余底部留白。
- 日报与归档：原黑色铭牌内加入今日／随机／往期；手机规格条收紧、封面与曲名并排，完整方形封面，正文与曲名字重更易读，常用操作有更大点击范围。
- 日报：即时搜索叠加收藏筛选，显示结果计数；取消最后一首收藏有明确空状态和恢复入口；收藏保持原浏览器跨期累计方式，异常存储与跨标签更新有处理，导出随收藏同步。
- 随机：保留原单曲唱盘结构；搜索可直选，组合筛选有数量／重置／无结果反馈；曲库加载有超时及重试；手机总数与标题并排，封面 220px 正方形。临时篮子仍只保存在当前标签会话。
- 试听：切歌隔离旧媒体事件及 Promise；加载中可取消；暂停后迟到事件不会自动播放下一首；失败可重试，日报自动跳过有上限；进度支持键盘。封面详情和试听是独立按钮。
- 详情：封面完整显示，关闭键保持可达；键盘焦点循环与返回，关联歌曲按曲名及艺人准确跳到随机页，迟到的艺人资料不会重置当前滚动。
- 构建：新增 `--render-only` 离线渲染已有内容，补 UI 自动测试及独立 JS 的发布触发路径。

## 本地复现

在此工作树运行：

```powershell
python -X utf8 scripts/build_daily.py --render-only
python -m unittest discover -s tests -v
python -X utf8 tests/test_catalog.py
python -m http.server 8901 --bind 127.0.0.1 --directory site
```

本机预览：`http://127.0.0.1:8901/`。这是电脑本机地址，不是手机外网预览链接；正式站及此前独立预览均未发布本轮 UI。

媒体异步状态处理依据 [MDN play()](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/play)，日报可键盘操作的进度采用 [原生 range 输入](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/input/range)。
