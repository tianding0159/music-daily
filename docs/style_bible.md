# 中文乐评 capsule 文案 · 文笔圣经

供每日音乐日报重写全部歌曲文案（artist_oneliner / why / scene 三字段）直接照写。核心心法一句话：**具体压倒抽象，判断压倒中立，画面压倒形容词，术语必接人话。每写完一句，问「这句能不能原样搬到另一首歌上」——能，就是陈词，重写。**

---

## 一、声音（整体 voice）

这套文案的说话人是**一个有品位、有判断、懂制作、但不端着的乐迷朋友，在跟另一个懂行的人说话**。五条支柱：

1. **懂行但不掉书袋**。可以点术语（808、切分音、多轨叠录、失真、混响尾巴、arpeggio），但术语后必须立刻接一句人话，说清它造成了什么听感。术语是锚，体验是钩——只有锚没有钩就是乐理笔记。
2. **克制而有观点**。敢下判断、敢给保留（"前半段像隔层毛玻璃，副歌才碎开"），不无脑吹。褒贬都往具体处落，从不骑墙说"各有特色"。
3. **有温度不煽情**。写画面、摆细节，让读者自己撞上情绪，而不是替他总结人生道理或喊"治愈你的疲惫"。冷静的旁观 + 克制的抒情。
4. **物质感优先**。写声音先落到一个能看见、摸到、尝到的实物或一个身体动作，而不是形容词。把"温暖"翻译成"雪松木盒里塞着熏香"，把"厚重"翻译成一个可感的画面。
5. **零营销腔**。不写"宝藏""封神""氛围感拉满""值得单曲循环"。这套文案的目的是让人**想按下播放键**，不是让人**觉得你很会夸**。

## 二、artist_oneliner 写法

**目标**：一句话给出艺人的辨识度 = **谱系/地理坐标 + 一个具体的声音特征或反差**。忌"才华横溢的音乐人"这类可套任何人的通稿词。冷、准、带一个具体信息。

**公式**：
> `[哪里人/什么场景/什么谱系一脉] + [一个具体到只对他成立的动作或声音标签]`

坐标负责"他站在音乐地图的哪里"，具体特征负责"别人做不出的那一下"。两者缺一：只有坐标像百科词条，只有特征像谜语。

**范例**：
- "冰岛人，把管风琴录进教堂再拆成尘埃的那类作曲家。"
- "密尔沃基旋律派说唱手，能把炫富曲写出人情味。"
- "小山田圭吾，把 Shibuya-kei 一路推到声音设计洁癖的那一个。"

## 三、why 写法（≤2 句）

**目标**：用**具体的声音/制作/情绪细节**让人想听，而不是空泛夸好听。

**骨架（两句制）**：
> **句 1** = 一个具体锚点（这首歌具体做了什么：哪件乐器怎么动 / 嗓音怎么变 / 编曲怎么推 / 一句歌词意象），至少带一个**带物理力度的动词** + 一个**可触摸的材质或物件**。
> **句 2** = 一个转折、反差或情绪落点（"但…""越听越…""看似 A，底色是 -A"），下一句有态度的判断。

**手法清单（每条 why 至少命中 2 项）**：
- **通感要翻译不要装饰**：把听觉转成视觉/触觉后信息量要**增加**（"嗓音磨损成多轨谐波的丝缕"——既写脆弱又写制作），不是堆感官词。
- **具体器乐/制作词**：808、切分音、失真贝斯、混响尾巴、多轨叠录、tape 饱和——但点到即止，只在能解释某个听感时出现。
- **一个精准动词**：碾过 / 浮起 / 结霜 / 渗 / 绷紧 / 拆开重铺 / 磨损 / 灌进来，取代"很有氛围"。
- **一个能拍成照片的画面**：把情绪落到具体物件（旧照片、毛玻璃、湿水泥、被单）。
- **克制的判断/反差**：给保留、给悖论句，一句话同时给听感和解读。

**范例**：
- "人声被叠成一片薄雾压在失真吉他上，前半段像隔着毛玻璃；副歌一到玻璃碎了，光全灌进来。"
- "吉他被处理成一块压缩磨损的声音材料，塞进冷硬的数字编辑框架里——明知终点是灾难，却始终保持优雅的推进。"
- "主歌钢琴几个高级和弦、几个切分音带出布鲁斯的黏，预副歌一个变速，甜得像刚开始的恋爱。"
- "只用一把长号，放大失真到你像住进了她吹气的风洞里——粗粝，但越听越暖。"

## 四、scene 写法

**目标**：一个**具体到身体、时间、光线、动作**的私人时刻，不是功能标签。忌"深夜 emo""下雨天必听""通勤时光""放松时听""闭上眼仿佛置身"。

**心法**：把"适合什么时候听"改写成一张能拍下来的照片——有时辰、有光、有一个具体动作或身体状态。

**范例**：
- "深夜末班地铁靠窗，车窗把你映成一个陌生人的那十分钟。"
- "退潮后独自走回岸上，鞋里还进着沙的时候。"
- "凌晨三点改完最后一版，把台灯关掉、还没起身的那口气。"
- "夏天午后车窗全开，等红灯时手指在方向盘上敲的那种松。"
- "洗完澡头发还滴水，坐在地板上不想开灯的十分钟。"

## 五、黑名单（中英文必避）

**中文陈词/鸡汤/营销体**：
空灵、治愈、天籁、天籁之音、洗涤心灵、净化、涤荡、直击灵魂、触动内心最柔软的地方、余音绕梁、令人陶醉、如痴如醉、耳朵怀孕、如梦如幻、醉人、慵懒；娓娓道来、缓缓流淌、层层递进、大气、磅礴、震撼人心；闭上眼仿佛……、仿佛置身……、带你走进……、让人沉浸其中、沉浸式；氛围感拉满、高级感、空气感、质感满满、颗粒感（除非真指失真质地）、后劲很大（无所指时）；宝藏歌手/专辑、神仙旋律、封神、天花板、殿堂级、教科书级、绝绝子、一整个爱住、视听/听觉盛宴；值得单曲循环、一听就上头；温暖的旋律、明亮的音色、干净的嗓音（除非立刻跟具体锚点）；"无论……都能……""适合放松/工作/睡前听"（万能适配句 = 没写）；鸡汤排比（"身处喧嚣守得住清醒"这类可贴任何专辑的处世格言）。

**英文（译介时同样避）**：
sonic landscape / sonic journey / sonic tapestry / soundscape（尤其 lush/vast soundscape）、hauntingly beautiful、ethereal、atmospheric（空用）、aural、lush（后不接具体乐器时）、soaring vocals、pulsating、infectious hooks、textural（空转）、a masterclass in…、tour de force、genre-defying / genre-bending、seamless fusion、effortlessly blends、instant classic、must-listen、"washes over you"、"takes you on a journey"、"at once X and Y"（万能句式）。

**替换准则**：想写一个抽象形容词时，逼问一次"具体是什么声音元素让它这样"——"空灵"是"混响拉很长、尾巴迟迟不落地"，就写后者。把结论换成证据，把形容词换成动词+物件。

## 六、before → after 改写示范

**A. artist_oneliner**
- before：小山田圭吾，Shibuya-kei 走向声音设计极致的鬼才。
- after：**小山田圭吾——把 Shibuya-kei 一路拆到单颗声音都要摆位的那个洁癖者。**
  （去掉"鬼才"这种通稿态度词，把"声音设计极致"落成一个具体动作"单颗声音都要摆位"，辨识度立刻上来。）

**B. why**
- before：用水滴声当节奏、把 stereo 空间当乐器，却始终有清亮旋律。制作洁癖者的天堂。
- after：**水滴声敲出节拍，声音在左右耳之间来回走位、像有实体，底下却始终浮着一条清亮的旋律不肯沉。听得见每一颗声音被摆在哪。**
  （"stereo 空间当乐器"这个术语转成可感画面"在左右耳之间来回走位、像有实体"；删掉"制作洁癖者的天堂"这句营销落点，换成一个更具体的听感判断"听得见每一颗声音被摆在哪"，动词"浮""不肯沉"带上力度。）

**C. scene**
- before：戴上耳机，想听清每一颗声音的位置时。
- after：**夜里关了灯，只戴一边耳机躺着，想数清每颗声音站在哪一侧的时候。**
  （加时辰、光线、身体姿势和一个具体动作"数清每颗声音站在哪一侧"，从功能提示变成一张能拍下来的照片，且呼应这首歌的声场特征。）
