# 先接入 1000 首曲目，保留现有界面

本次只把已核验的 1000 首发现曲目接入原版「今天听点别的」随机曲库。原有 1169 首加上新曲，随机曲库共 2169 首。首页与随机页仅更新曲目总数；页面模板、CSS、JavaScript 和原有交互保持不变。

新曲来自 Apple 官方元数据，覆盖 339 位艺人，每位艺人最多 3 首。全部记录已通过身份、版本标题、专辑归属、语义去重及试听链接检查。完整原始记录与当时的检查证据保存在 reports/catalog-expansion-2026-09-07/；这些历史检查文件原样保留，其采集脚本位于 codex/music-ui-library 开发分支。

新曲在原有卡片里显示「待精选」。发行年份来自 Apple 当前收录版本，不能当成已查证的原版年份；旋律、BPM、心情、制作、场景及逐首听感没有伪造或从种子歌曲复制。

data/discovery.json 是新曲的记录源。data/pool.json 仍是 1169 首正式精选池，日刊只从该池选曲。因此本次入库不会改写历史、当期歌单、精选规则或通知状态。曲目未来进入正式精选池后，随机曲库优先保留正式记录，避免重复出现。

每日构建、纯站点发布和简介导入都从同一处合并随机曲库数据，后续重建不会丢失这 1000 首。数据变化也会触发原有纯发布流程；本次不触发微信通知。

UI 改版保留在草稿 PR #1，暂缓合并。本次不包含新版导航、布局、搜索、收藏、试听交互或新发现页面。

验证入口：

- python3 tests/test_catalog.py
- python3 -m unittest discover -s tests -p 'test_discovery_library.py' -v
- python3 scripts/healthcheck.py

正式池与日刊状态需保持不变，模板及前端脚本需与本次基线一致；另对接入幂等性、正式曲优先、1000 首媒体信息和待精选状态进行回归检查。
