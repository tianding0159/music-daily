# Music Taste Profile（选曲/补池的唯一依据）

**核心原则**：按**气质(Mood) + 制作美学(Production) + 旋律(Melody)**判断，**不按流派**。好听永远第一；旋律必须存在（可哼唱）。喜欢有旋律、有空间感、有细节、能长期循环、不易听腻的作品——"越听越舒服"胜过"震撼"。小众不是目的，值得反复循环才是。

**关键词**：温柔 / 空气感 / 颗粒感 / 松弛 / 城市夜晚 / 夏天傍晚 / 雨天 / 木质感 / organic electronic（数码与自然融合）/ 怀旧又现代 / 精致但不炫技 / 有人味。

**制作偏好**：analog warmth、tape saturation、soft compression、cassette texture、少量vinyl crackle、granular texture、subtle glitch、field recording、优秀reverb空间设计、宽stereo、柔和高频、舒服中频、不刺耳。电子元素要"像空气/像呼吸"。**忌**：EDM、future bass、过度sidechain、为炫技堆插件。

**旋律**：必须存在、能记住、听完能哼。忌纯氛围堆叠 / drone / 长时间无主题 / 只有texture没有melody。

**节奏**：70–120 BPM；relaxed groove / shuffle / laid-back / bossa influence / jazz groove / broken beat / downtempo / soft breakbeat。**忌**：festival EDM / hard techno / dubstep / trap drop / 大鼓过重。

**人声**：轻柔、自然、不炫技、像在耳边唱；breathy / whisper / layer harmony / soft falsetto；男女皆可。

**器乐**：吉他（clean / chorus / jangle / fingerstyle / nylon / jazz / midwest-emo，带点lo-fi录音感）；钢琴（felt / upright / jazz，不要过度古典）；贝斯（温暖圆润木质、jazz bass，不要808炸低频）；合成器（Juno / Prophet / DX7 / M1、模拟，pad重要，不要尖锐lead）。

**偏好流派（权重高→低）**
-Shibuya-kei, Folktronica, Indietronica, Ambient Pop, Organic Electronic, Dream Pop, Japanese Indie Pop, Jazz Pop, Sophisti-pop, Downtempo, Bedroom Pop（优秀）, City Pop（真优秀）, Midwest Emo, Sampledelia, Ambient Folk, Quiet Alternative R&B, Leftfield Pop, Hypnagogic Pop, Chamber Pop, Soft Post-rock
-Trip-Hop, Slowcore, IDM（旋律型）, Neo Soul, Modern Bossa, Electro-acoustic, Minimal Electronica
-Shoegaze, Post Punk, Art Pop, Indie Rock, Psychedelic Pop

**黑名单（命中即排除）**：Hyperpop / TikTok Pop / AI感重的bedroom pop / 模板化dream pop / 廉价city pop revival / 爆款indie pop / Festival EDM / Dubstep / Big Room / Hardstyle / Metal / Progressive House / Future Bass / Phonk / Lo-fi Hip Hop study beats / 只有氛围没旋律的ambient / 以noise为主的experimental / Math rock炫技 / Jazz fusion炫技。

**艺人特征偏好**：日本独立音乐人、电子民谣、自己制作、真实乐器、录音有空气感、作品完整（偏好整专辑语境）。

**评价排序**：① 好听 ② 耐听 ③ 制作精致 ④ 独特气质 ⑤ 易循环 ⑥ 整体审美。**不因**历史地位 / 高分 / 经典 / 热门而推荐。

**总开关**：像Pitchfork编辑 + Bandcamp Daily选曲人 + Resident Advisor的电子乐耳朵 + 一个听了二十年独立音乐的朋友一起推荐——找那些一听就想收藏、一个月后还在循环、十年后依然想起的作品。不追猎奇、不追冷门、不追评分、不追热门。

**探索方向锚点（仅校准方向，不要只推这些）**：Lamp / cero / Cornelius / Fishmans / 大貫妙子 · Bibio / Four Tet / múm / The Album Leaf / Boards of Canada · Beach House / Men I Trust / Yumi Zouma / Mild High Club / Blood Orange / Sampha · American Football / toe / Khruangbin / Cinematic Orchestra / Portishead。**以锚点为圆心找相邻/更深/大概率没听过的作品。**
