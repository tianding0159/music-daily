# UI 与曲库更新 · 2026-09-07

页面改为暖纸色、墨黑和橙色的音乐日刊，首页、日报、随机页、往期和新发现共用导航。保留唱机与小猫；曲名保持原始大小写，正文和手机操作区扩大。

## 页面与操作

- 首页使用原生链接直接进入日报，取消强制等待和全局 Enter/空格拦截；关闭 JavaScript 仍能浏览。
- 日报支持多词搜索、流派与收藏交叉筛选、清空筛选、明确空结果、收藏导出、复制失败时手动复制、跨标签页收藏同步。
- 随机页支持搜索直选、气质/流派/年代筛选、筛选数量、重试、快速点击防重与临时篮子清空撤销。
- 艺人详情采用曲目 ID 跳转，日报、随机和归档使用正确的相对路径。详情与试听为两个独立原生按钮；模态有焦点约束和关闭后焦点恢复。
- 试听控制处理失效地址、拒绝自动播放、上一首迟到的异步错误、重试恢复、关闭与最多 30 秒上限。全局快捷键不抢输入框、链接、按钮和模态的键盘事件。
- 往期可按月份、日期和歌单名称查找。

## 新发现的准确范围

`data/discovery.json` 新增 1000 首可搜索、试听、收藏的作品，来自 339 位已收录艺人的已有专辑，每位艺人最多 3 首。它们与正式池、批内其他曲目的语义键及 Apple ID 无重复。

1000 首均通过 Apple 官方曲名、艺人、专辑归属及版本记录核对；1000 个试听地址均返回有效音频类型和 M4A 文件头。证据、采集时间和 SHA-256 在 `reports/catalog-expansion-2026-09-07/`。

这些是「新发现 / 待精选」。Apple 元数据和可获取的音频不能证明听感、BPM、旋律或制作判断，因此未为凑数量生成这些字段或模板乐评。正式每日精选池仍为 1169 首，本次没有改动历史选曲和艺人简介。当前来源为 Apple 美区；页面年份代表该发行版本，不必然等于首次发行年份。

## 修复与构建

`itunes.py` 改为整词识别版本标记、保留 Unicode 曲名及艺人、拒绝空身份匹配、双向核对版本，并重新核对已接受缓存的实际曲目。Deliver、Meditation、韩文歌名及 Live 缓存错配都有回归用例。

新增 `python scripts/build_daily.py --render-only`：只用现有快照及媒体缓存重建全站，不联网、不生成新一期、不修改数据或推送状态。发布工作流覆盖共享 UI 源文件和新发现数据；PR 工作流运行离线回归与资源守卫。

## 浏览器 API 依据

- [Clipboard.writeText](https://developer.mozilla.org/en-US/docs/Web/API/Clipboard/writeText)：安全上下文与失败回退。
- [HTMLMediaElement.play](https://developer.mozilla.org/en-US/docs/Web/API/HTMLMediaElement/play)：Promise 拒绝和自动播放限制。
- [HTMLElement.inert](https://developer.mozilla.org/en-US/docs/Web/API/HTMLElement/inert)：详情浮层的背景交互隔离。
